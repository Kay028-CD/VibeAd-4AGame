# VibeAd 氛围创想 4A 协同体验

这是可直接部署到 GitHub Pages 的静态网页包。

## 部署

1. 新建一个 GitHub repository。
2. 解压本压缩包，把里面的全部文件上传到 repository 根目录。
3. 打开 repository 的 **Settings → Pages**。
4. 在 **Build and deployment** 中选择 **Deploy from a branch**。
5. Branch 选择 `main`，文件夹选择 `/ (root)`，点击 **Save**。
6. 等待约 1–3 分钟，GitHub 会显示访问地址。

注意：不要把整个压缩包文件本身上传后期待它自动解压；请先解压，再上传里面的文件。`.nojekyll` 文件请保留。
